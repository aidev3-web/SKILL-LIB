## 2026-11-05/06 · The builder is born; test deck Northgate Trading Corp. (fictional)

Six slides from `client-profile.json`; one file with everything inlined.
- **Built:** `template/deck.html.j2` (CSS + engine + six slides), `build_deck.py` (profile → `deck.json` → HTML, with the pain library and app flow), `check_deck.py`, `shots.py`, `deliver.py`. - **Bugs the first shots caught:** Jinja autoescape turned the QR SVG into invisible text (a 2,100px card) and escaped the font CSS (fonts silently fell back); `all:unset` buttons lost focus rings; short Gantt bars clipped labels; the client's green equalled the hypercare green. All fixed in the template/builder (engine.md, Gotchas).
- **Impeccable round 1 (two isolated Sonnet agents):** critique 24.5/32 applicable (~31/40). Acted on: slide 4 arrived as seven bare dots for three presses (now arrives complete, cascading discipline by discipline, no presses); step text 17 → 18px with shorter lines; slide 5's "Plan rule" line repeated its badge (now the line is the "Select a phase" cue); the users pill on slide 3 read as a tinted tile (now bare icon + text). - **Audit round 1:** 16/20. Fixed: a blank 7th print page (`.slide:last-of-type{break-after:auto}`; shots.py now prints and fails on anything but 6 finished pages), labels under 16px, Gantt bars 46 → 56px (24px on a phone at 0.433 scale), `.hl` forced on in print, navy colours tokenised. - **Motion sweep (find-animation-opportunities gate):** kept three. The slide 3 progress wire jumped (CSS cannot transition the SVG `x2` attribute) and now scales with the card. The slide 5 detail line rises in when it changes. Stations and bars got press feedback. Rejected hover lifts, slower pushes and a second spring. The slide 4 loop arrow drew only partly: `vector-effect:non-scaling-stroke` breaks a `pathLength` dash draw, so the arrow is drawn in pixel coordinates.

- **Shell gotcha (again):** a bash heredoc holding the engine's `$$(` helper tripped the rm safety check. Write patch scripts to `~/ClaudeWork/nextcore-presentation/qa/*.py` with the Write tool and run them with `python -I -X utf8`.

## 2026-11-08 · Framework, lapse hunt and borrowed skill craft
- **User:** "enrich the skill for building presentation. create a framework and check all lapses and needed to be address. use different github skills to improve the reasoning and skill building and design."
- **Framework:** `reference/framework.md`, six gated stages (brief, story, slide craft, claims, review, delivery) with the headline-only test, proof before ask, split never shrink, a different composition per slide, the AI-tell list, a rationalisation table and the lapse register.
